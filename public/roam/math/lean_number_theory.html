Number Theory in Lean 4

2026-05-23

Summary

Elementary number theory: divisibility, primes, GCD, modular arithmetic — verified in Lean 4 with Mathlib.

Setup

Lean 4imports
import Mathlib.Data.Nat.Prime.Basic
import Mathlib.Data.Nat.GCD.Basic
import Mathlib.Tactic

Divisibility

For a,b∈N, we write a∣b if ∃k,b=ak.

Lean 4div
-- 6 divides 42
#eval Nat.dvd_iff_mod_eq_zero.mpr (by norm_num : 42 % 6 = 0)

example : 6 ∣ 42 := by norm_num
example : ¬ (7 ∣ 42) → False := by simp  -- 7 does divide 42
example : 7 ∣ 42 := by norm_num

GCD and Bézout

The GCD satisfies gcd(a,b)=gcd(b,amodb) (Euclidean algorithm).

Lean 4gcd
#eval Nat.gcd 48 18      -- 6
#eval Nat.gcd 100 75     -- 25

-- Bézout coefficients via extended Euclidean
#eval Nat.xgcd 48 18     -- (s, t) with 48s + 18t = gcd

-- gcd(m, n) divides both m and n
example (m n : ℕ) : Nat.gcd m n ∣ m := Nat.gcd_dvd_left m n
example (m n : ℕ) : Nat.gcd m n ∣ n := Nat.gcd_dvd_right m n

Primes

A prime p has no divisors other than 1 and p.

Lean 4primes
#eval Nat.Prime 2     -- true
#eval Nat.Prime 9     -- false (9 = 3 × 3)
#eval (Finset.range 20).filter Nat.Prime  -- primes < 20

-- Infinitely many primes (classic result in Mathlib)
#check Nat.infinite_setOf_prime

-- Every n ≥ 2 has a prime factor
example (n : ℕ) (hn : 2 ≤ n) : ∃ p, Nat.Prime p ∧ p ∣ n :=
  ⟨n.minFac, Nat.minFac_prime (by omega), Nat.minFac_dvd n⟩

Modular Arithmetic

For a,b,n∈Z, a≡b(modn) iff n∣(a−b).

Lean 4modular
-- ZMod n is the type ℤ/nℤ
#eval (7 : ZMod 5)        -- 2
#eval (3 : ZMod 5) + 4    -- 2  (7 mod 5)

-- Fermat's little theorem: a^p ≡ a (mod p) for prime p
example (p : ℕ) [Fact (Nat.Prime p)] (a : ZMod p) : a ^ p = a :=
  ZMod.pow_prime_eq a
