Inner Product Space

2026-01-27

Summary

An inner product space is a vector space equipped with an additional operation called an inner product. This operation allows us to define geometric notions such as length, angle, orthogonality, norm, distance, convergence, and completeness.

The conceptual chain is:

inner product⟹norm⟹metric⟹convergence⟹completeness.

Basic Setup 基本设.

Let F be a scalar field. Usually,

F=R

or

F=C.

Let V be a vector space over F.

That is, V is equipped with:

  • vector addition

    +:V×V→V,

  • scalar multiplication

    ⋅:F×V→V.

An inner product is a function

⟨⋅,⋅⟩:V×V→F.

For v,w∈V, we usually write

⟨v,w⟩∈F.

Axiomatic Definition of an Inner Product 内积的公理化定义

define

Let V be a vector space over F, where F=R or F=C.

An inner product on V is a function

⟨⋅,⋅⟩:V×V→F

satisfying the following axioms.

  1. Conjugate symmetry 共轭对称性:

    ⟨v,w⟩=⟨w,v⟩​

    for all v,w∈V.

  2. Additivity in the first variable 第一变量加法线性:

    ⟨v1​+v2​,w⟩=⟨v1​,w⟩+⟨v2​,w⟩

    for all v1​,v2​,w∈V.

  3. Homogeneity in the first variable 第一变量齐次线性:

    ⟨λv,w⟩=λ⟨v,w⟩

    for all λ∈F and all v,w∈V.

  4. Positive-definiteness 正定性:

    ⟨v,v⟩≥0

    for all v∈V, and

    ⟨v,v⟩=0⟺v=0.

If such a function is given, then V is called an inner product space.

Note

Here we use the mathematical convention: the inner product is linear in the first variable and conjugate-linear in the second variable.

也就是说，这里采用数学约定：第一变量线性，第二变量共轭线性。

Consequence: Conjugate Linearity in the Second Variable 第二变量共轭线性

Because of conjugate symmetry and linearity in the first variable, the inner product is conjugate-linear in the second variable.

That is, for all v,w1​,w2​∈V and all λ∈F,

⟨v,w1​+w2​⟩=⟨v,w1​⟩+⟨v,w2​⟩,

and

⟨v,λw⟩=λ⟨v,w⟩.
Proof

We first prove additivity in the second variable.

Using conjugate symmetry,

⟨v,w1​+w2​⟩=⟨w1​+w2​,v⟩​.

By additivity in the first variable,

⟨w1​+w2​,v⟩=⟨w1​,v⟩+⟨w2​,v⟩.

Therefore,

⟨v,w1​+w2​⟩=⟨w1​,v⟩+⟨w2​,v⟩​.

Using the rule a+b​=a+b, we get

⟨v,w1​+w2​⟩=⟨w1​,v⟩​+⟨w2​,v⟩​.

By conjugate symmetry again,

⟨w1​,v⟩​=⟨v,w1​⟩

and

⟨w2​,v⟩​=⟨v,w2​⟩.

Hence,

⟨v,w1​+w2​⟩=⟨v,w1​⟩+⟨v,w2​⟩.

Now we prove homogeneity in the second variable.

Using conjugate symmetry,

⟨v,λw⟩=⟨λw,v⟩​.

By homogeneity in the first variable,

⟨λw,v⟩=λ⟨w,v⟩.

Therefore,

⟨v,λw⟩=λ⟨w,v⟩​.

Using the rule ab=ab, we obtain

⟨v,λw⟩=λ⟨w,v⟩​.

By conjugate symmetry again,

⟨w,v⟩​=⟨v,w⟩.

Hence,

⟨v,λw⟩=λ⟨v,w⟩.

Therefore, the inner product is conjugate-linear in the second variable.
