# Lean 4 Integration

Aaronote supports embedded Lean 4 blocks in markdown notes, turning each note into a live Lean module with Jupyter-style per-cell output.

## Overview

- `#+begin lean4` … `#+end lean4` blocks inside a note are concatenated into a single `.lean` file under `.lean/<note-path>.lean` in the notes root.
- The notes root acts as the Lean project root (with `lakefile.toml` + `lean-toolchain` placed there by the user once).
- A `lake serve` process is spawned on demand and killed after 30 s of inactivity.
- Per-block output (`#eval`, `#check`, errors) appears inline below each block.
- A left-side **Infoview** drawer shows the goal state at the cursor and a full diagnostic list.

## Setup

1. In your notes root, create `lean-toolchain` and `lakefile.toml`:

```toml
# lakefile.toml
name = "AaronNotes"
defaultTargets = ["AaronNotes"]

[[require]]
name = "mathlib"
git = "https://github.com/leanprover-community/mathlib4"
rev = "v4.25.1"          # pin to same rev as your Workshop

[[lean_lib]]
name = "AaronNotes"
srcDir = ".lean"         # mirrors your .md tree
```

```
# lean-toolchain
leanprover/lean4:v4.25.1
```

2. Run `lake update` once to fetch Mathlib.

3. From now on, any note with a `lean4` block gets its `.lean` mirror auto-generated and kept in sync.

## Writing Lean blocks

```markdown
# Group Axioms

Let $G$ be a group.

#+begin lean4 GroupMul
import Mathlib.Tactic

variable (G : Type*) [Group G]
#+end lean4

#+begin lean4 Proof
example (a b : G) : a * b * b⁻¹ = a := by simp
#eval 1 + 1
#+end lean4
```

- Blocks are stitched in document order into one `.lean` file.
- The optional title after `lean4` is just a label; it doesn't affect compilation.
- Imports go in the first block (or any block — order is preserved).

## Mirror tree

`.lean/<relative-note-path>.lean` is generated on every save and kept alive in memory while editing. The first line is:

```lean
-- AUTOGENERATED FROM <note-path> — DO NOT EDIT BY HAND
```

Each block is wrapped in cell markers (transparent to Lean):

```lean
-- @cell 0 begin
<block 0 body>
-- @cell 0 end
```

## LSP lifecycle

| Event | Action |
|---|---|
| Note with lean4 block opened | `lake serve` spawned (if not running); `.lean` file written; `textDocument/didOpen` |
| Note edited (debounced 400 ms) | `textDocument/didChange` (full sync) |
| Note saved | `.lean` file written to disk |
| Note closed | `textDocument/didClose` |
| 30 s idle (no open lean docs) | `shutdown` + kill process |

## Infoview panel

Open with the **Lean** toolbar button or `Cmd+Shift+L`.

- **Goals** — tactic state at cursor (`$/lean/plainGoal` + `$/lean/plainTermGoal`)
- **Expected type** — term-mode elaboration type
- **Messages** — per-note diagnostics; click to jump

A translucent grey bar marks ranges still being elaborated (`$/lean/fileProgress`).
